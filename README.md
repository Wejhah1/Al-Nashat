# النشاط الثقافي — 1448 هـ

منصة عربية (RTL) لإدارة مسابقة مدرسية: مجموعات وأعضاء ونقاط وكروت وتحضير بالـ QR، مع متصدرين لحظيين وبوابة متابعة للطالب ولوحة تحكم كاملة.

## التقنية
- **الواجهة:** React 19 + Vite + TypeScript + Tailwind CSS 4 + Motion
- **الخلفية:** Supabase (Postgres + Realtime + Auth + Storage + Edge Functions)
- كل عملية على النقاط (تحضير، نقاط، كروت، نقل، وسام، تراجع) تتم داخل **دالة Postgres واحدة ذرية** مع قيد سجل، فلا تكرار ولا فساد في الأرصدة.

## التشغيل محلياً
```bash
npm install
npm run dev
```
الإعدادات الافتراضية تشير لمشروع Supabase الخاص بالنشاط. لتغييرها انسخ `.env.example` إلى `.env.local`.

## النشر (Vercel)
1. اربط المستودع بـ Vercel (Framework: Vite).
2. أضف المتغيرين `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` (اختياري).
3. ملف `vercel.json` يعيد توجيه كل المسارات إلى التطبيق.

> الكاميرا تتطلب HTTPS — تعمل تلقائياً على Vercel.

## الصفحات
| المسار | الوصف |
|---|---|
| `/` | الرئيسية: ترتيب المجموعات، الأوائل، الأخبار، شريط الأحداث |
| `/leaderboard` | منصة التتويج + المجموعات بقوائم منسدلة + ترتيب الأعضاء |
| `/display` | وضع البروجكتر (ملء الشاشة) |
| `/log` | سجل النقاط العام بالتاريخ الهجري |
| `/rules` | لائحة النقاط والكروت والأوسمة |
| `/news` | الأخبار والفعاليات |
| `/me` | بوابة الطالب (رقم الجوال أو مسح البطاقة) |
| `/admin/*` | لوحة التحكم (مدير عام / مشرف) |

## الصلاحيات
- **مدير عام:** كل شيء.
- **مشرف:** التحضير، النقاط، الكروت، النقل، الأوسمة، التراجع، التقارير.

## قاعدة البيانات
ملفات الترحيل في `supabase/migrations` ودالة إدارة المشرفين في `supabase/functions/admin-users`.
